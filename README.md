# Value of Information

Code exploring value of information

## Code for Chapter 4 of the thesis: `idealised_example/`

### Set-up code files:
+ `config.py`: Specify all constants for analyses.
+ `location_funcs.py`: Functions to plot a location given the index, return the array of EAI and exposure, and get indices of land locations.
+ `spatial.py`: Functions to load the land-point grid indices and lat/lon coordinates. (Relies on `config.py`, `location_funcs.py`)
+ `sampling.py`: Functions to generate samples of the epistemic inputs $X_e$ and the corresponding $Y_e(d)$ loss values, for use by both the modified PAWN and VoI sensitivity methods. (Relies on `config.py`, `location_funcs.py`)
+ `utility.py`: Calculates utility from $Y_e(d)$ values. (Relies on `config.py` only if we went back to a non-financial utility function)
+ `precompute_samples.py`: Precompute the shared X_e sample and every location's Y_e(d), and cache the result to `samples_cache.npz` (Relies on `config.py`, `spatial.py`, `sampling.py`)

### Modified PAWN-specific code

+ `modified_pawn.py`: Functions to apply the modified PAWN method to the shared $X_e$ / $Y_e(d)$ samples generated by `sampling.py` (Relies on `config.py`, `sampling.py`, `utility.py`)
+ `run_modified_pawn_all_locs.py`: Run the modified PAWN sensitivity analysis across every location in a precomputed samples cache (`samples_cache.npz`), and save the resulting $S_i$ values (with bootstrap CIs) to `pawn_results.npz`. (Relies on `config.py`, `precompute_samples.py`, `modified_pawn.py`)

### Value of information-specific code

+ `voi.py`: Functions to apply the value of information method via the smoothing-based estimator of Straub et al. (2025) (Relies on `config.py`, `sampling.py`, `utility.py`)
+ `run_voi_all_locs.py`: Run the value-of-information analysis across every location in a precomputed samples cache (`samples_cache.npz`), and save the results to `voi_results.npz`. (Relies on `config.py`, `precompute_samples.py`, `voi.py`)

### Summary code files

+ `generate_figures.py`: For a set of modified PAWN and VoI results, generate all plots for the chapter. (Relies on `config.py`, `sampling.py`, `precompute_samples.py`, `utility.py`, `modified_pawn.py`, `run_modified_pawn_all_locs.py`, `run_voi_all_locs.py`, `voi.py`)

### Other code files

+ `location_check.py`: Generates $X_e$ / $Y_e(d)$ samples for a single location and print out a summary, as well as plot the distribution of $Y_e$. Also plots the percentage of samples where each decision was optimal in a location and the optimal decision under uncertainty. (Relies on `config.py`, `spatial.py`, `sampling.py`)
+ `speed_test.py`: Compares the speed of modified PAWN and VoI methods in one location. (Relies on `precompute_samples.py`, `modified_pawn`, `voi`)


### Older attempts: `original_code/`

+ `example_voi.py`: Calculating information value for a particular location using the sampling method. Calls `calc_Ye`, which no longer exists, but might be replaceable by `calc_Ye_jit` from `sampling.py`. (Relies on `location_funcs.py`)
+ `refactored_example_voi.py`: Refactored calculation of information value for a particular location using the random forest method. (Relies on `location_funcs.py`)
